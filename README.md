# Simple-Interest-Calculator
Simple Interest Calculator
Description

This is a simple Python menu-driven program that calculates Simple Interest based on:

Principal Amount
Rate of Interest
Time Period

The program also calculates the total amount after adding the simple interest to the principal amount.

Features
Calculate Simple Interest
Calculate Total Amount
Menu-driven interface
Exit option included
Formula Used

SI=
100
P×R×T
	​


Where:

P = Principal Amount
R = Rate of Interest
T = Time in Years
Concepts Used
Functions
while loop
if-elif-else
User Input
Arithmetic Operations
Formatted Strings (f-strings)
How It Works
Program displays a menu.
User selects:
1 → Calculate Simple Interest
2 → Exit
User enters:
Principal Amount
Interest Rate
Time Period
Program calculates:
Simple Interest
Total Amount
Result is displayed on the screen.
